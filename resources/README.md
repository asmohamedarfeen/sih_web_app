# 🎨 Resources & Static Assets

Storage for media assets, brand iconography, custom fonts, logos, and mock datasets.

## Folders
- `icons/`: SVG & PNG interface icons.
- `logos/`: Emblems, unit badges, and application logos.
- `images/`: High-resolution UI illustrations and background textures.
- `fonts/`: Typography files.
- `mock-data/`: Static fixture JSON/CSV datasets for testing and frontend prototyping.
