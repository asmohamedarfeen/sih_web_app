# 🤖 AI & Machine Learning Services

This directory encompasses the AI microservices responsible for predictive analytics, stress categorization, burnout forecasting, explainable SHAP breakdowns, and prescriptive counseling recommendations.

## Pipeline Structure
- `stress-prediction/`: Real-time stress scoring models based on biometric, attendance, and duty logs.
- `burnout-prediction/`: Long-term cumulative burnout risk forecasting.
- `recommendation-engine/`: Welfare intervention and counseling recommendations.
- `explainable-ai/`: SHAP and feature attribution modules for actionable officer transparency.
- `feature-engineering/`: Shift burden indicators, deployment fatigue, and physiological telemetry indicators.
- `model-training/`: Model training, hyperparameter optimization, and cross-validation scripts.
- `model-serving/`: Fast inference APIs and model loading pipelines.
- `preprocessing/`: Ingestion, scaling, and feature normalization.
- `datasets/`: Training data schemas, synthetic generators, and anonymized datasets.
- `experiments/`: ML tracking, experiment logs, and model comparisons.
- `evaluation/`: Accuracy, ROC-AUC, precision, recall, and fairness audit benchmarks.
