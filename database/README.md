# 🗄️ Database Management

This directory manages database schemas, migrations, seed datasets, automated backups, and database maintenance scripts for PostgreSQL / SQLite.

## Structure
- `migrations/`: Alembic migration scripts.
- `seed/`: Initial database seeding data (roles, standard permissions, admin accounts, baseline questionnaires).
- `backup/`: Database dump scripts and backup archives.
- `scripts/`: Initialization, reset, and migration runner scripts.
